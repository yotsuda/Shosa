# 依頼 3・4: 録音を入れた書き出しの時刻と、録音に合わせて歌う声（2026-11-20）

宛先: Lily# のセッション（`C:\MyProj\LilySharp`）。差出: Shosa のセッション（`C:\MyProj\Shosa`）。
一覧: [REQUESTS.md](REQUESTS.md) の 3 と 4。

## 背景（オーナーの使い方）

1. Suno で伴奏（歌なし）を作って `.mp3` を得る。または市販の曲から Orecchiante が分けたパートで歌だけを抜く。
2. Orecchiante でコード譜（`.lys` と隣の `.orecchiante.json`）を作る。
3. AI がコード譜のセクションとコード進行に合わせてメロディと歌詞を書く。
4. **Lily# の歌唱シンセが、`.mp3` とぴったり合う時刻で歌う。** 録音のパートと歌声の音量は Lily# のプレビューで混ぜ、書き出す。
5. Shosa（動きをテキストで書く言語）の VRM のキャラクターが、同じ時刻で歌いながら踊る。Shosa は隣の `.orecchiante.json` を
   自分で読み、拍ごとのテンポで録音に合わせて踊る（Shosa DESIGN.md 97 節）。音は Lily# が書き出したものを鳴らす（オーナー決定:
   混ぜるのは Lily#、Shosa はそれを鳴らすだけ）。

このためには、Lily# の書き出した音が**元の録音と同じ秒の上にある**こと、歌声が**録音の揺れに付いていく**ことが要る。

## 依頼 3: 速さ 1.0 で書き出しても、録音が約 0.07% 伸びる

オーナーが Lily# から書き出した `%USERPROFILE%\OneDrive\Documents\Transcribe!\source\糸 (Bank Band)_ボーカル抜き.mp3`
（速さを変えず、歌のパートを切って書き出したもの）を、元の `糸 (Bank Band).mp3` と比べた。

| | 元の録音 | 書き出し |
|---|---|---|
| 長さ（ffprobe） | 285.048 s | 285.257 s（+0.209 s） |
| 音の出始め（-40 dB を越える所） | 1.806 s | 1.840 s |

低い音（150 Hz 以下）の立ち上がりの相互相関（8 kHz モノラル、5 ms ごとの包絡、±0.3 s、15 秒の窓）で、書き出しは少しずつ遅れる:

| 窓の始め | 書き出しの遅れ | 相関 |
|---|---|---|
| 10 s | +45 ms | 0.36 |
| 120 s | +110 ms | 0.35 |
| 180 s | +150 ms | 0.40 |
| 230 s | +180 ms | 0.30 |
| 265 s | +245 ms | 0.48 |

約 0.07% ゆっくりで、長さの差（+0.209 s ÷ 285 s = 0.073%）とも合う。波形そのものや高い音では相関が 0.1〜0.2 しかなく測れなかった
（書き出しは伸縮のエンジンを通るので、波形が元と一致しない）。測りの道具は ffmpeg と numpy（Orecchiante の `.venv`）。

- 心当たり: `recording-design.md` 7 節の「`recordingPlan(sound, practice.speed × warpFit).rate` を速さにして」。速さ 1.0 でも
  `warpFit` の分だけ録音が伸び縮みしているのかもしれない。
- **お願い**: 練習の速さが 1.0 のときは、書き出しの録音が元の録音と同じ秒の上にある（伸縮しない、または 1 標本の誤差で戻る）こと。
  先頭も、Count-in がなければ書き出しの 0 秒が録音の 0 秒（今は出始めが 34 ms 遅い。MP3 の符号化の遅れの分かもしれない）。
- できれば、書き出しが元の録音の秒の上にあることを見張る試験（伸縮しない経路を通ったこと、または長さが一致すること）。

## 依頼 4: 歌い手の声が録音の揺れに付いていくこと

`recording-design.md` 7 節の「残る穴: 歌い手の声は録音の揺れについて行かない（§5 の ⑴ と同じ）」を埋めてほしい。

- 録音のある `.lys` を録音と一緒に鳴らす・書き出すとき、歌い手（cantoria）に渡す音節の秒を、楽譜の音と同じ `timeWarp`
  （隣のファイルの小節と拍の秒）で録音の秒に移す。録音は小節ごとにテンポが揺れる（糸 (Bank Band) は 51.9〜67、平均 61.37）ので、
  楽譜のテンポ 61.5 のままの秒だと、歌は 39 小節目で 1.49 秒ずれる。
- プレビューと書き出しの両方で。Shosa は書き出したものを鳴らすので、書き出しが要る。

## 相談（依頼ではない）: 混ぜた音のファイルを Shosa が見つける道

Shosa は書き出した音を、踊りの 0 秒（= 隣のファイルの `bars[0].start`）に合わせて鳴らしたい。今は書き出したファイルの場所を
知る道がない。案: Lily# が録音を入れて書き出したとき、隣のファイルにそのファイル名を書く（例 `"mix": "糸 (Bank Band)_ボーカル抜き.mp3"`、
`audio` と同じ読み方、録音と同じ秒の上にあることが条件）。Shosa はあれば `mix` を、なければ `audio` を鳴らす。
形はオーナーと Lily# 側で決めてよい（Shosa の `.shosa` に書く案もある）。
