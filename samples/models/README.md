# Characters for the samples

`hello.shosa` and `juggle.shosa` dress their dancers in VRM models that are **not in this repository**
(a `.vrm` here is ignored by git). Without them the dancers are drawn as sticks, and the
preview says which file it did not find; everything else works.

| File here | Model | From |
|---|---|---|
| `zundamon.vrm` | Zundamon (humanoid) 3D model set, 2025 ver. A1 — the VRM 1.0 file of the set | <https://zunko.jp/> |
| `zunko.vrm` | Tohoku Zunko 3D model set, 2023K — the VRM 1.0 file of the set | <https://zunko.jp/> |

Zunko stands in for Shikoku Metan, who sings the second part of the song: there is no free model of Metan.

`juggle.shosa` has two more jugglers:

| File here | Model | From |
|---|---|---|
| `shino.vrm` | Sendagaya Shino, a sample model of the beta VRoid Studio, converted to VRM 1.0 by Coatie (Koh-Tee) | <https://hub.vroid.com/characters/4593660874193246717> |
| `sample.vrm` | VRM1_Constraint_Twist_Sample, © 2022 pixiv Inc. | <https://github.com/vrm-c/vrm-specification/tree/master/samples> |

These two say their terms in the file itself (the VRM 1.0 licence fields): use by anyone, commercial use,
alteration and redistribution are allowed, and credit is not required. The page of Sendagaya Shino's set
says its models are CC0.

The models of Zundamon and Zunko are © SSS LLC. and are used under their own terms (a VN3 licence, in each set:
`*_vn3license_*.pdf`), not under Shosa's MIT licence. Read them before using the models. In short,
as of the sets downloaded in November 2026: non-commercial use only; videos and streams (YouTube
included) are allowed; no sexual, violent, political or religious use; adjusting and converting the
file is allowed, altering the model needs the owner's permission; credit is not required.

Any other VRM model works the same way: put its path on the `dancer` line.
